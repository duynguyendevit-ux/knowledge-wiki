Interfaces in Unity

What are Interfaces?

Interfaces định nghĩa contract - một set of methods mà class phải implement. Cho phép treat different classes như cùng type.

Key Concepts

  • Contract: Class phải implement tất cả interface methods
  • Multiple Interfaces: Class có thể implement nhiều interfaces
  • Polymorphism: Dùng interface type thay vì concrete type
  • No Implementation: Interface chỉ declare, không implement

Code Example

When to Use

  • Use when: Nhiều different classes cần shared functionality
  • Good for: Damage systems, Interaction systems, Collectables
  • Avoid when: Chỉ có 1-2 classes, hoặc cần shared implementation

Interfaces vs Inheritance

  • Interfaces: “Can do” relationship, multiple allowed
  • Inheritance: “Is a” relationship, single parent only

Common Interfaces in Unity

Best Practices

  • Prefix interface names với “I” (IDamageable, IInteractable)
  • Keep interfaces focused - single responsibility
  • Use TryGetComponent<Interface>() thay vì GetComponent
  • Document interface contracts clearly
