Unity Action

Overview

Action trong Unity là một ready-made delegate có thể có một hoặc nhiều parameters và returns void. Actions rất hữu ích để tạo loosely coupled connections giữa scripts thông qua event system.

How It Works

Action vs Delegate:

  • Delegate: Phải declare delegate type trước
  • Action: Ready-made, không cần declare type

Event keyword:

  • Prevents other classes from invoking the action
  • Other classes chỉ có thể subscribe (+= ) và unsubscribe (-=)
  • Invoking chỉ có thể từ declaring class

Common Use Cases

  • Global game events: Level complete, game over, pause/resume
  • Player events: Player died, collected item, leveled up
  • Input events: Button pressed, gesture detected
  • System callbacks: Save completed, data loaded
  • UI events: Menu opened, button clicked

Best Practices / Tips

Always Unsubscribe

Tại sao quan trọng?

  • Nếu không unsubscribe → memory leak
  • Object destroyed nhưng vẫn subscribed
  • Có thể gây null reference exceptions

Action vs Input Actions

⚠️ Don’t confuse:

  • System.Action: C# delegates (events/callbacks)
  • Input Actions: Unity Input System feature (input handling)

These are completely different systems!

Actions vs UnityEvents

Choose Action when:

  • Pure code communication
  • Performance critical
  • No Inspector setup needed

Choose UnityEvent when:

  • Designers need to hook up events in Inspector
  • Prototyping/visual scripting
