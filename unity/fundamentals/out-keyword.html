Unity Out Keyword

Overview

Từ khóa out trong C# cho phép một function trả về thêm thông tin ngoài return type của nó. Out keyword đảo ngược flow của data - thay vì pass data vào function, nó pass data ra function.

How It Works

Normal function parameters:

  • Data flows IN → function sử dụng data
  • Function returns ONE value qua return type

Out parameters:

  • Data flows OUT → function assign value cho parameter
  • Function có thể return MULTIPLE values (return type + out parameters)
  • Out parameter must be assigned trong function

Common Use Cases

  • Raycast operations: Return bool + hit data
  • TryParse methods: Return success + parsed value
  • Dictionary lookups: Return success + value
  • Physics queries: Return collision + collision data
  • Custom validation: Return valid/invalid + error message

Best Practices / Tips

  • Must assign out parameter trong function - compiler sẽ báo lỗi nếu không
  • Inline declaration (C# 7.0+):
  • Discard unused out values với underscore:
  • Out parameters useful khi function cần return success status + data
  • Prefer out khi both return value và additional data đều quan trọng
  • Avoid overusing - quá nhiều out parameters làm code khó đọc

Out vs Ref vs Return

out:  Function assigns value, caller doesn't need to initialize
ref:  Function modifies value, caller must initialize first
return: Single value, simplest và clearest khi chỉ cần 1 giá trị
