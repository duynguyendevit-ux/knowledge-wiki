Async / Await in Unity

What is Async?

Async/Await cho phép execute code không đồng bộ, không block main thread. Khác với Coroutines, async chạy trên background thread.

Key Concepts

  • async keyword: Đánh dấu method là asynchronous
  • await keyword: Wait for task completion
  • Task: Đại diện cho async operation
  • Non-blocking: Main thread tiếp tục chạy

Async vs Coroutines

Async/AwaitCoroutines
Runs on background threadRuns on main thread
Survives object destructionStops when object destroyed
Can return valuesCannot return values
Needs cancellation tokensAuto-stops with object
Better for heavy operationsBetter for frame-based timing

When to Use

  • Use when: Heavy computations, loading assets, network calls
  • Good for: File I/O, API calls, scene loading
  • Avoid when: Simple delays, WebGL builds, need tight Unity integration

Best Practices

  • Luôn use try/catch/finally với cancellation
  • Cancel tasks trong OnDestroy()
  • Không reference Unity objects trong background thread
  • Task.Delay dùng milliseconds, không phải seconds
  • Use await thay vì .Result để tránh deadlocks
